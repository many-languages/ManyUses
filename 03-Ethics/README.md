# 03-Ethics

IRB/ethics materials for the two studies behind this project.

```
03-Ethics/
  Study1_MSU/   # Study 1 -- the previously published paper
  Study2_HU/    # Study 2 -- the current study (Many Uses)
```

## Study 1 (`Study1_MSU/`)

The **previously published paper** this project builds on (the Affordance
Norms work — see `Affordance_Norms_2-main/` and `Affordance_Norms_OSF-main/`
at the repo root). Ethics materials here are historical record for that
prior study, not active approval for current data collection.

- `Maxwell Affordances IRB Application.docx` — the IRB application
- `Norming Sample Materials.docx` — study materials submitted with it
- `Debriefing Form-Affordances.docx` — participant debriefing form

## Study 2 (`Study2_HU/`)

Ethics materials for the **current study** (Many Uses) — this is the
active approval covering the data collection this repo's `02-Task/`
pipeline runs.

- `HU_Consent_Form.docx` — participant consent form
- `HU_Debrief.docx` — participant debriefing form

Once the consent form here is actually wired into the formr survey flow,
the participant-code/lab-ID data it produces is what
`06-Visualization/README.md`'s placeholder `load_consent_codes()` is
waiting to be pointed at instead of synthetic demo data.
